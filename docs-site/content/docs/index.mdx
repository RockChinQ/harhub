# 团队 Agent Harness 的控制平面

Harhub 把散落在个人电脑、代码仓库和聊天记录里的 Agent 能力，变成团队可治理、可复用、可交付的资产。当前 Library 以标准 **Agent Skills** 为核心；Project 还能盘点仓库中的 MCP 配置、Rules 与 Agent Instructions。

## 你可以用 Harhub 做什么

- **Library**：上传、校验、预览、搜索、版本化、下载和分享标准 Agent Skills。
- **Forge**：从需求访谈生成一个可下载、可继续维护的项目 Harness。
- **Projects**：连接现有 GitHub 仓库，盘点 Skills、MCP、Rules 和 Instructions，查看漂移并通过 PR 交付变更。
- **Agent Operations**：让 Agent 通过结构化 MCP tools 或可脚本化 CLI 完成同样的工作。

> Harhub 不创造私有 Skill 格式。Skill 仍是包含 `SKILL.md` 的标准目录或 zip 包，遵循 [Agent Skills 规范](https://agentskills.io/specification.md)。
