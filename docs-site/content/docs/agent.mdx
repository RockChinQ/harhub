---
title: 给 Agent 使用 Harhub
description: 在 CLI、MCP 和 Harhub Agent Skills 之间选择。
---

Harhub 提供三层 Agent 接口，它们互补而不是互斥。

| 方式 | 最适合 | 特点 |
| --- | --- | --- |
| CLI | Shell Agent、CI、一次性脚本 | 可组合，所有远程命令支持 `--json`。 |
| MCP | 长对话 Agent、IDE Agent | 结构化参数、工具注解、确认门和路径边界。 |
| Harhub Skills | 需要稳定操作流程的 Agent | 教 Agent 如何组合 MCP tools、确认写操作和恢复中断。 |

## 推荐组合

先安装 npm 包并登录一次：

```bash
npm install -g harhub@beta
harhub login
```

然后把 `harhub-mcp` 加入 Agent 的 MCP 配置，并安装仓库内三个 Harhub Skills。CLI 和 MCP 默认复用同一份登录状态，不需要把 Token 放进 Prompt。

## 安全原则

- 先读后写：确认 Workspace、Asset、Project 或 Forge Session 的当前状态；
- 删除、撤销分享、安装到本地、打开 PR、发布到 Library 等高影响操作必须明确确认；
- 不把 Access Token 作为 MCP tool 参数；
- 下载默认不覆盖已有文件；
- 本地文件操作只能位于 `HARHUB_MCP_ALLOWED_ROOTS` 内。
