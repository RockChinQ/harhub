## Skill 包要求

一个 Skill 是包含 `SKILL.md` 的目录或 zip。`SKILL.md` 至少包含标准 frontmatter：

```md
---
name: code-review
description: Review a change for correctness, security, and maintainability.
---
```

Harhub 遵循 agentskills.io 的字段与约束，不定义额外必需的私有格式。

## 上传与扫描

- **目录扫描**：CLI 递归发现所有 `SKILL.md`。
- **任意 zip 布局**：Web 和 `assets upload` 可扫描含多个嵌套 Skill 的仓库导出包。
- **独立存储**：每个选中的 Skill 都拆分到自己的对象存储前缀，原始 zip 被丢弃。

## 版本规则

上传和编辑都会创建不可变版本。Harhub 保留最近五个版本，并允许下载或恢复历史版本。需要改一个文件时，可使用：

```bash
harhub skills edit <skill> --file SKILL.md --content-file ./SKILL.md
harhub download <skill> --version 2 --output ./skill-v2.zip
```

## 分享规则

分享页只公开 Skill 的公开元数据、文件预览和可验证下载。撤销分享后旧 URL 失效：

```bash
harhub share <skill>
harhub unshare <skill>
```

MCP 配置不允许公开分享。

## MCP 配置

Library 中的一个 MCP 资产对应一个 JSON 文件，顶层使用 `mcpServers` 或
`servers`。Harhub 保留原始内容及最近五个不可变版本，并提取 server 名称、
数量与 transport 等安全元数据用于浏览和 Forge 选择。

```bash
harhub assets upload ./mcp.json --kind mcp \
  --name "Issue tracker" \
  --description "Use for projects connected to the team issue tracker."
```

凭据应使用环境变量占位符。若 secret-like 环境变量包含字面量，校验会给出警告。
配置值不会进入 Forge 的 AI prompt。
